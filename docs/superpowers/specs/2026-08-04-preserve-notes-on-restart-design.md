# Obsidian 再起動時のノート復元

## 背景

プラグインは Obsidian のレイアウト準備完了時に、内部コマンド `workspace:close-others-tab-group` を実行している。
この処理はプラグインの起動ごとに発火するため、Obsidian が保存済みワークスペースを復元した直後にノートを閉じてしまう。

## 目的

Obsidian の再起動時に、保存済みワークスペースのノートとタブを Obsidian 標準の動作どおりに復元する。
既存のインデントコマンドと行入れ替えコマンドの挙動は変更しない。

## 設計

`main.ts` から `onLayoutReady` に登録しているタブ整理処理を削除する。
この処理だけが利用している `Platform` import も削除する。

設定による切り替えや代替コマンドは追加しない。
起動時にワークスペースを変更する要件がなくなったため、Obsidian のワークスペース復元処理へ介入しない構成が最小かつ十分である。

## エラー処理

削除後は内部コマンド API にアクセスしないため、コマンド定義の有無や実行失敗を処理するコードは不要になる。

## 検証

- 起動時に `workspace:close-others-tab-group` を呼び出すコードが存在しないことを自動テストで確認する。
- TypeScript の型検査と production build が成功することを確認する。
- 既存の四つのエディタコマンドが `main.ts` に残ることを確認する。

Obsidian 上での最終確認では、複数のノートを開いた状態でアプリを再起動し、同じノートとタブが復元されることを確認する。
